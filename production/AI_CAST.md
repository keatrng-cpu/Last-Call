## HOW TO USE (consistency system)

1. Generate each character's **anchor portrait** first (prompt below, square).
2. Reuse the anchor via image-reference/character-reference features
   (Midjourney `--cref`, Flux Redux/reference, Runway character reference) for
   every subsequent shot, appending the scene prompt from the storyboards.
3. Never regenerate an anchor after approval — faces are locked like locations.
4. Style suffix for ALL character generations:
   `cinematic still, Kodak 250D film grain, natural unglamorous lighting,
   rust-belt Ohio realism, 85mm portrait lens, photorealistic --ar 4:5`
